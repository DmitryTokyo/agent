# agent

Здесь лежит всё, что мои агенты используют во всех проектах: общий порядок работы, мои скиллы, чужие наборы, у
которых я учусь, и каталог, где искать новые. Правила конкретного проекта живут в его репозитории.

## Что где лежит

```
~/dev/agent/
  workflow/      как мы разрабатываем с агентом и где лежат знания
  agent-kit/     мои скиллы (git: DmitryTokyo/agent-kit), оглавление в INDEX.md
  references/    чужие наборы, только для чтения; отсюда ничего не подключено
  README.md      этот файл
```

## Порядок работы и карта знаний

В `workflow/README.md` описан порядок работы с агентом во всех репозиториях: как задача проходит путь от моей фразы
до слитого PR, как называются ветки и коммиты, как устроено ревью и как агент учится на поправках. Там же список
того, что каждый репозиторий решает сам: режим работы, префикс задач, язык, стек.

`workflow/knowledge-map.md` — карта знаний. По ней видно, где в репозитории лежит каждый вид знания: задачи, планы,
решения, термины, правила агента, поправки. У каждого факта одно место, остальные на него ссылаются. Репозиторий
дописывает свои строки в `docs/knowledge-map.md`.

`workflow/START.md` — как начать работу в репозитории: короткий опрос, `AGENTS.md`, выбор скиллов. Агент читает его,
когда я прошу работать по общим правилам или когда в репозитории нет `AGENTS.md`. Об этом сказано в
`~/.claude/CLAUDE.md` и `~/.codex/AGENTS.md`, сами правила агент без повода не читает.

Если правило репозитория расходится с общим, прав репозиторий. Правило, полезное всем проектам, переносим сюда.

Подключённые скиллы лежат в `~/.agents/skills`. Codex читает эту папку сам. Claude Code читает `~/.claude/skills`, а
там на каждый скилл стоит ссылка в `~/.agents/skills`. Поэтому набор у обоих одинаковый.

`agent-kit` глобально пока не подключён. В его скиллах стоят заготовки `{{p}}` и `{{work}}`, поэтому проект копирует
нужные скиллы к себе и заполняет их (как именно, написано в `agent-kit/INDEX.md`).

## Правила

В глобальном наборе только скиллы, которыми я пользуюсь сейчас. Перестал пользоваться — убираю скилл из
`~/.agents/skills` и `~/.claude/skills` и пишу строку в раздел «Убраны» ниже. В настройках харнессов скиллы не
выключаю: у Claude и Codex эти выключатели лежат в разных файлах и быстро расходятся.

Вернуть скилл: `npx skills add <источник> --skill <имя>` или скопировать его папку в `~/.agents/skills` и поставить
ссылку:

```bash
ln -s ../../.agents/skills/<name> ~/.claude/skills/<name>
```

Если беру чужой скилл и переделываю его, он переезжает в `agent-kit`. В первой строке пишу, откуда он и с какого
коммита, чтобы потом сравнить с новой версией автора.
