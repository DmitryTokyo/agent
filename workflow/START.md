# Начать работу в репозитории

Цель — начать работу за 5–10 минут. Агент читает этот файл, когда пользователь просит работать по общим правилам или
когда в репозитории нет `AGENTS.md`.

## 1. Опрос

Сначала агент смотрит в репозиторий: язык, менеджер пакетов, git remote, есть ли `AGENTS.md`, `CLAUDE.md`,
`CONTRIBUTING.md`. Что видно оттуда, не спрашивает. Остальное спрашивает по одному вопросу и к каждому даёт свою
рекомендацию:

1. Что это за проект, одной фразой?
2. Как работаем: прямо в `main` (быстрая помощь, утилита) или ветки и PR?
3. Где лежит код: GitHub, GitLab, только локально?
4. Только для веток и PR: где задачи и какой у них префикс?
5. На каком языке общаемся и пишем задачи?
6. Какие скиллы берём? Агент предлагает набор из `~/dev/agent/agent-kit/INDEX.md` «Pick by project» по ответу на
   вопрос 1.

Пользователь отвечает «просто помоги» → режим «прямо в `main`», вопросы 4 и 6 пропускаются, скиллы не копируются.

## 2. Файлы

Агент пишет и показывает пользователю:

- `AGENTS.md`, до 40 строк: проект одной фразой, ответы опроса как настройки репозитория (список «Что решает
  репозиторий» в [`README.md`](README.md)), ссылка на `~/dev/agent/workflow/README.md` и строка «правила репозитория
  важнее общих»;
- `CLAUDE.md` из одной строки: `@AGENTS.md`.

Если `AGENTS.md` уже есть, агент дописывает недостающие настройки и ничего не удаляет.

Скиллы агент копирует по `~/dev/agent/agent-kit/INDEX.md` «Take skills into a project».

## 3. Готово

Опрос закончен, когда пользователь утвердил `AGENTS.md` и выбранные скиллы лежат в репозитории. Тогда агент
спрашивает: «С чего начнём?»
